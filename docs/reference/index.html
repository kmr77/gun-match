GunMatchが目指すこと

狩猟に特化した、道具を探しやすく、人とつながりやすい場所へ。

メール・電話番号認証

会員登録時に連絡先を認証。
認証状況を分かりやすく表示。

所持許可あり表示

プロフィールで自己申告を表示。
許可証の確認済みを意味しません。

サイト内でやり取り

メールや電話番号を公開せず、
メッセージ履歴を残せます。

「探す」登録と通知

欲しい条件を公開して待てます。
合う掲載があればお知らせ。

利用の流れ

詳しい使い方を見る →
  1. 1

    会員登録

    メール・SMS認証を行い、基本情報を登録します。

  2. 2

    「譲る」「探す」を掲載

    品物の情報、または探している条件を登録します。

  3. 3

    サイト内で相談

    メッセージで条件を確認し、必要な手続きを進めます。
