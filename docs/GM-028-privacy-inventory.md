# 個人情報棚卸し・規約公開前レビュー用文案

更新日：2026-11-05
状態：内部レビュー用。法務確認・運営情報・保存期間の確定前に、公開規約・プライバシーポリシーとして使用しないこと。

この資料は現行Laravel実装で確認できた保存項目と関連処理を整理したものです。法令上の義務、事業者の運用、委託先、保存期間を推定で確定するものではありません。GunMatchの最終MVP仕様と、現在実際に提供している機能は別に扱います。

### 退会時の関係整理

- 実装はアカウント行の削除であり、関連情報全体の一括消去を意味しません。
- `users` を参照するSMSチャレンジは削除されます。通報・監査ログ等は履歴の参照整合性を保つためuser参照をnull化し、記録本体は残ります。
- 通報本文・対象情報・管理者メモ、問い合わせ本文・メールアドレスは、会員IDとの外部キー有無にかかわらず残る可能性があります。自由記述に個人情報が含まれる場合の確認・削除手順は未整備です。
- 退会後に法令・不正対応・監査のため何をどの期間保持するか、退会者へどう説明するかは運営・法務判断が必要です。保存期間を推測して自動削除する処理は追加していません。
- 現在のローカルlog mailerはメール宛先・本文をログへ記録し、メール確認・パスワード再設定URLを含み得ます。実在会員のメールを使った検証は避け、ログのアクセス・保持・消去方法と本番でlog mailerを無効にするデプロイ確認を決める必要があります。実際の `.env` の内容やログの保存先・保持状態は本調査では確認していません。

## 利用規約・プライバシーポリシーの現状

- `/terms` と `/privacy` は準備中の案内ページです。正式本文として公開・適用される状態ではありません。
- `/register` から両ページへリンクしていますが、本文を確認して同意する実装・同意記録はありません。登録画面の案内だけで同意取得済みとは扱いません。
- 運営者の正式名称・住所・連絡先、適用法令上の表示要件、情報の利用目的と必要性、保存期間、委託・第三者提供、開示等請求への対応、退会後の保持、問い合わせ窓口の運用は未確定です。
- SMS事業者は未選定で、実SMS配送は未実装です。メール設定はローカルログ出力を含む開発設定であり、本番配送は未確認です。
- 会員確認審査は管理者向け状態・方法・日時・メモの記録です。本人確認書類画像・証明書番号は収集しません。SMS電話確認、会員確認審査、所持許可の自己申告は別の情報です。
- 通報・問い合わせは運営向けの別機能です。会員間取引メッセージ、銃器等の掲載・取得募集・マッチングは現在の提供機能ではありません。最終MVP構想と現行提供範囲を混同しない説明が必要です。

## 公開前に必要な決定

- 運営者情報と、個人情報に関する正式な問い合わせ先。

- メール・SMS・ホスティング等の委託先、第三者提供、越境移転の有無。
- 本人からの開示・訂正・利用停止・削除請求の受付・本人確認・対応期限。
- 規約・ポリシー本文の法務確認、登録時の同意方式と同意記録、公開・発効手順。
- 本番SMTP／SMSの契約・認証情報の安全管理。現時点では実配送未確認。
